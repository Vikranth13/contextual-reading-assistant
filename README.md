# Contextual Reading Assistant

A Chrome extension that helps users understand unfamiliar words without leaving what they are reading.

Users can select a word on a webpage and receive its dictionary definition, pronunciation, and an AI-generated explanation of how the word is being used in the surrounding sentence.

## MVP

- Detect selected words on webpages
- Extract surrounding sentence context
- Display a floating definition popup
- Show dictionary definition and pronunciation
- Generate contextual explanations with AI
- Save vocabulary locally
- Cache previous lookups
- Provide basic extension settings

## Technology

- React

### Backend
